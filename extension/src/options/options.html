Фильтр канбан-доски Azure DevOps Server по исполнителям. Настройки сохраняются сразу и синхронизируются с вашим профилем браузера.

Серверы Azure DevOps

Расширение работает только на серверах из этого списка. При добавлении браузер спросит разрешение читать страницы сервера.

    Кого считать участником карточки

    Типы дочерних элементов Исполнители этих элементов тоже участвуют в карточке. Чаще всего это Task.
    Завершённые состояния Дочерние элементы в этих состояниях не учитываются, когда включено «Только незавершённые задачи».
    Поля, которые не считаются участием Системные имена полей истории изменений, например System.CreatedBy.
