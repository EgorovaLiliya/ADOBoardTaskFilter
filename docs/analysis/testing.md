# Проверка

## Стенд

Расширение проверяется автоматически, три набора проверок запускаются одной командой:

```
npm install
npx playwright install chromium
npm test
```

| Набор | Файл | Что проверяет |
|---|---|---|
| Доска | `tests/content.test.js` | Скрипт расширения на имитации канбан-доски и REST API Azure DevOps: отбор, мультивыбор, поиск, сброс, встроенный фильтр, дозагрузка, смена доски, ошибки, настройки, большая доска |
| Настройки | `tests/options.test.js` | Страница настроек с имитацией `chrome.storage` и `chrome.permissions`: серверы, доступ, списки, переключатели, сброс |
| Расширение | `tests/extension.test.js` | Настоящая загрузка расширения в Chromium: манифест, service worker, регистрация скрипта, страница настроек |

Результаты сохраняются в `tests/results.json`. Скриншоты для документации: `node tests/run.js --shots docs/img`.

## Что не проверялось автоматически

- Работа на настоящем сервере Azure DevOps: разметка доски, пересчёт высоты дорожек после скрытия карточек.
- Окно браузера с запросом разрешения: в проверках выдача доступа имитируется.
- Автообновление по таймеру (FR-21): минимальный интервал — минута.
